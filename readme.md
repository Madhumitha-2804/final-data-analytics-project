# Hotel Booking, Revenue and Cancellation Analysis

## Project Overview
Data analysis project focused on hotel bookings, revenue,
customer behavior and cancellation patterns.

## Tools Used
- Python
- Pandas
- BeautifulSoup
- PostgreSQL
- Excel
- Power BI

## Project Workflow
Python Data Cleaning
→ Web Scraping
→ SQL Analysis
→ Excel Analysis
→ Power BI Dashboard

## Key Analysis
- Booking trends
- Cancellation rate
- Average ADR
- Customer type analysis
- Lead time cancellation
- Country-wise bookings
- City Hotel vs Resort Hotel
